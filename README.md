# CivicTrack AI

**Your city. Your voice. Real change.**

CivicTrack AI is an AI-powered civic issue reporting and tracking platform. It helps citizens report problems such as potholes, garbage accumulation, broken streetlights, and water leakage.

The platform aims to identify the issue, determine its location, find the responsible government authority, and help citizens submit and track complaints.

## Project Goals

- Make civic issue reporting easier.
- Use AI to identify and categorize reported issues.
- Capture the geographical location of complaints.
- Identify the responsible government department.
- Help citizens submit complaints through official channels.
- Allow citizens to track complaint progress.

## Getting Started

### Frontend Setup

1. Clone the repository.
2. Open the project folder in VS Code.
3. Navigate to the frontend directory:

   `cd frontend`

4. Install dependencies:

   `npm install`

5. Start the development server:

   `npm run dev`
